# Contributing to DesignatedDriver

DesignatedDriver is an Expo/React Native service prototype for coordinating a customer's own vehicle getting home safely, with customer, driver, and admin flows backed by Supabase.

Before a pull request, follow the README setup and verify the role-specific trip flow you changed. Changes to dispatch, RLS, evidence uploads, vehicle inspection, trip state, or admin controls should include focused regression checks.

Keep demo/test data clearly synthetic and separate from production configuration.

A merged commit is not automatic approval for a production deployment.
